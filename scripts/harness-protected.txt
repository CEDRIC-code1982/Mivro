# Files that make up the harness. Single source of truth, read by:
#   - scripts/hooks/pre-bash-guard.py  (refuses shell writes to them)
#   - scripts/hooks/pre-edit-guard.py  (refuses Write/Edit on them)
#   - scripts/harness-lock.sh          (hashes the tracked ones into scripts/harness.lock)
#
# One repo-relative path per line. A trailing `/**` covers the whole directory.
# Changing this list is itself a harness change: the lock catches it.
#
# Since J-045 the harness is ALSO everything outside the product zones
# (scripts/hooks/harness_paths.py PRODUCT_DIRS / PRODUCT_ROOT_FILES): dotfiles,
# tool configs, package.json, lockfiles... are harness without being listed.
# This list matters most for files INSIDE the product zones (sensor tests, the
# stdlib override) and as the fallback of older harness-guard copies.
#
# Why each group is here: a sensor that the agent can rewrite is a suggestion,
# not a sensor (JOURNAL-ECHECS J-029).
